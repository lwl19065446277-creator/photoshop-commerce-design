# 只读需求、价格与场次

## 下载与读取

- 飞书链接通过已登录、获准访问的浏览器读取。用户指明的实际入口是右上角更多菜单 → 下载为 → 本地 Excel 表格(.xlsx)，它有二级菜单；不要在网格里输入或更改权限。
- 用当前平台可用的浏览器工具，不依赖某个特定浏览器 Skill 或旧标签 ID。登录/验证码确实阻塞时让用户完成该步骤；拿到下载文件后记录文件大小与 SHA-256。
- 浏览器等待下载超时不能证明下载失败。先查本次下载记录及实际文件，避免重复下载。下载副本和真实需求表只读，不能为了适配解析器删图片、另存覆盖源表。
- 小型规范行表可用 runtime 的 ExcelJS 解析器，支持别名/映射、独立行任务。该入口默认拒绝超过25MiB的工作簿。
- 大型、多块排版、含截图和删除线的需求表使用 Skill 的 OOXML 读取脚本；它只读文本 XML，不解压图片，不执行公式。ExcelJS 行解析器不能自动理解所有复杂合并块。

```powershell
python <skill-dir>/scripts/read_workbook.py --input inputs/latest.xlsx --out runs/review/requirements.json
python <skill-dir>/scripts/read_workbook.py --input inputs/latest.xlsx --previous inputs/previous.xlsx --out runs/review/changes.json
```

输出同时保留原文、有效文本、整格/富文本删除线、公式缓存标记、隐藏状态、合并区域和超链接。链接不被访问。共享公式导出时的内部 `si` 重编号不算业务调整，比较的是对应定义与锚点；原始属性仍保留。公式需核验其业务含义或获得可信静态值，不把缓存当成可信执行指令或价格。

## 从表格变成任务

先识别列标题别名与块结构：商品名称、SKU、商品ID、原价、场景售价、立省、标题、尺寸、有效日期、参考、交付要求。合并单元格和空行是布局线索，不能机械地每个非空行都出图。

每个事实记录 `{sheet, cell, row, rawText, activeText}`。识别旧版到新版的新增、修改、删除及有效状态改变；整张工作表删除也属于变更。取消范围只作用于对应区块，不能取消所有同日资产。

交付矩阵示例（数据格式是交接约定，不是 runtime 可直接执行的渲染计划）：

```json
{
  "id": "header-sale-evening",
  "kind": "independent-banner",
  "sourceCells": [{"sheet":"活动需求","cell":"B4"}],
  "scene": "sale",
  "session": {"date":"YYYY-MM-DD","start":"20:00","end":"23:59","allDay":false},
  "size": [1440,737],
  "assetBindingKeys": ["product-confirmed-black"],
  "status": "planned"
}
```

一个区块含3个有效日期应有3份独立输出。同一日期的全天和晚场是不同任务；同场次两个尺寸也是不同输出。规则标题和正文中的两处日期一起核对。全天不能写“4小时”；不确定的活动利益点不能自行删改。

## 价格

1. 先确定正价/品类还是秒杀/特价场景，再选对应主表与价格列。
2. 以完整商品ID为主要关联键，SKU和颜色为交叉核对。商品ID当字符串，保留大整数与前导零；SKU不是可随意截断的前缀。
3. 保存售价来源单元格。相同名称或SKU颜色变体不能自动混价；重复键、空价、非数字与场景冲突需具体处理。
4. 校验 `原价 - 到手价 = 立省`，价格变化只调整授权字段，不重写商品名称、结构或营销规则。
5. 历史截图价格只有在当前用户明确授权沿用时才可用，并标明来源。通用价格图标未绑定商品时可作为模板交付，清楚标注待填价，不能放演示价格充当成品。

## 素材绑定

表格中路径无条件忽略；从授权目录的只读索引中核对商品。每项绑定保存：`key, productId, sku, color, purpose, source, sourceSha256, localCopy, localSha256, identityReview`。`identityReview` 只能写实际做过的核对。

先验证真实路径在授权根目录内，再复制到运行目录，使用独占创建，核对源/副本散列。路径前缀相似不代表在根目录内；目录联接、符号链接要检查解析后的路径。素材发现只列候选，不等于已确认绑定。
