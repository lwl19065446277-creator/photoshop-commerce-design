# 从参考学习到实际排版

## 让“高级”变成可执行判断

先看用户授权的原版 PSD、成图和参考文件，记录具体观察，再决定变化。用户要求只改价格条渐变时，不能顺手重做字体、商品卡和照片风格。

需要线上研究时查当前可访问的品牌官网、设计师作品和字体官方资料。注明来源和观察范围；页面未加载、只读到标题或历史快照时，不宣称已看过整页。不要下载或照搬别家商品、Logo与成图作为交付素材。

研究记录采用“观察 → 推断 → 本次动作”，例如：

| 观察 | 本次动作 | 如何检查 |
| --- | --- | --- |
| 原页品牌、标题、优惠、时间分成四层 | 保持同一对齐线；时间独立于长标题 | 实际 PS 文字边界、手机缩略预览 |
| 原商品卡是灰底照片加白价区 | 使用现成带Logo灰底图，保留价格白底 | 对比原版和新图的卡片边界 |
| 参考摄影主导画面、装饰少 | 等比保留鞋型，用有限配色及少量细线 | 鞋底/鞋尖完整，主体不被文字遮挡 |

不要把某一版配色和字号变成所有品牌的固定规范。先确定画面尺寸、用途、商品体量、阅读距离和长文案，再设字号、行距及留白。

## 字体与文字

- 获取本机 Photoshop 的字体目录，使用真实 PostScript 名称；不要只凭系统字体显示名猜 API 字段。没有目标字体时明确记录替代，不让软件静默回退。
- 原版需保留时读取文字样式范围和段落样式。整层设置字体或改写内容可能破坏混排，不能把新文字匹配视为保留了全部样式。
- 品牌、活动标题、利益点、日期/规则形成清晰层级，字号与字重服务阅读顺序。少用无意义的大段英文或装饰小字填空。
- 给最长标题、四位售价、最长日期、最长规则留足空间。先测字，再换行和设置行距；不能只靠预估字符数。
- Photoshop 点文字的 `x/y` 在本运行时按文字锚点/基线处理，不能当 CSS 左上角。以实际回读的 bounds 校正；CR与LF可以规范化比较，不能因此丢掉标点与空格。
- 原价用真实文字删除线，并回读其样式；不要画一根坐标线假装随价格长度自动变化。

## 网格、构图与照片

- 先标安全边距、列宽、商品卡间隔和对齐轴。保留原版时从实际图层 bounds 测量步距，不凭截图猜固定坐标。
- 商品默认等比 `contain`。需要裁图时检查鞋尖、鞋跟、鞋底、Logo和模特关节，不能裁掉关键商品部位；不拉长、压扁或生成修改鞋型。
- 同款不同颜色、大片与白底图分用途核对；不能只用同款名称推断照片里的商品身份。
- 带Logo灰底成图通常直接使用，不再把鞋抠出后重新造底或重复加Logo。Logo和原图本身的灰阶保持。
- 羽化用于摄影接缝/背景过渡，不是把商品边缘整体模糊。使用可编辑渐变蒙版，确定从哪一段完整可见到哪一段透明；在黑、白底和实际合成中检查是否出现灰边、白边、断层或鞋子被擦掉。
- 主图图标的空白主图区必须是真透明。副标如果要求透明，仅文字有像素，不能加一块不透明底遮住商品。用Alpha通道检查，白色查看器背景不代表不透明。

## 配色与复核

从品牌和照片提取主色、文字色、中性色与强调色。优惠信息需要足够对比，避免浅底浅字。渐变沿原效果的角度、色标位置和透明度仅改RGB，特别是在用户仅授权变色时。

先做代表小样：一张摄影头图、一张最长规则、一张四位价格卡、一张全天透明图标。检查真实 PS 预览及保存后重新打开的版本。缩略联系页适合看整套一致性，原尺寸用于看文字锯齿、边缘和接缝。

视觉修改指令要能执行，例如“图层A向左移24px，标题B行距从72改为84，摄影蒙版起点向左移40px”；不要只说“再高级一点”。修改轮次有上限，无法确定的商品身份/审美要求留给人工判断，不宣称视觉模型绝对可靠。
